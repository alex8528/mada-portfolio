The null model appears as a horizontal line because it predicts the same value for every observation. The dose only model falls along a few horizontal lines because dose only takes a small number of values. The full model looks better overall, but there is still noticeable scatter around the diagonal line.

Bootstrap uncertainty for Model 2

set.seed(rngseed)
dat_bs <- bootstraps(train_data, times = 100)

pred_bs <- matrix(NA, nrow = 100, ncol = nrow(train_data))

for (i in 1:100) {
  dat_sample <- analysis(dat_bs$splits[[i]])
  
  bs_fit <- linear_reg() %>%
    set_engine("lm") %>%
    fit(Y ~ DOSE + AGE + SEX + WT + HT, data = dat_sample)
  
  pred_bs[i, ] <- predict(bs_fit, new_data = train_data)$.pred
}

preds <- apply(pred_bs, 2, quantile, c(0.055, 0.5, 0.945)) %>%
  t() %>%
  as.data.frame()

colnames(preds) <- c("lower", "median", "upper")

boot_plot_df <- train_data %>%
  select(Y) %>%
  bind_cols(
    predict_new2 %>% select(.pred),
    preds
  )

ggplot(boot_plot_df, aes(x = Y)) +
  geom_point(aes(y = .pred), alpha = 0.7) +
  geom_point(aes(y = median), shape = 1) +
  geom_errorbar(aes(ymin = lower, ymax = upper), alpha = 0.4) +
  geom_abline(slope = 1, intercept = 0, linetype = "dashed") +
  coord_cartesian(xlim = c(0, 5000), ylim = c(0, 5000)) +
  labs(
    title = "Observed versus predicted values with bootstrap uncertainty",
    x = "Observed Y",
    y = "Predicted Y"
  )

The bootstrap plot shows uncertainty around predictions. Some points have wider intervals, meaning predictions are less certain. The model captures part of the pattern, but there is still noticeable prediction error.
