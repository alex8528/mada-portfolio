Tidy Tuesday: Global Health Spending

Author

Alexandra Tejada-Strop

Published

April 21, 2026

This analysis uses the WHO Global Health Expenditure Database (GHED), which includes data on health spending for 195 countries from 2000 to 2023. The dataset shows how much countries spend on health care and where that funding comes from, including government spending, private sources, and external aid.

The main question guiding this analysis is:

Can we predict a country’s out-of-pocket payment burden (as a percentage of total health spending) based on the share of funding from government, private, and external sources?

This question matters for public health because high out-of-pocket costs can make it harder for people to access care and may lead to financial strain. This is especially true in low- and middle-income countries (World Health Organization, 2024), where individuals often bear a larger share of health care costs.

# Define a recipe for preprocessing
# We center and scale all predictors since LASSO needs this
oop_recipe <- recipe(oop_pct ~ govt_pct + private_pct + external_pct + year,
                     data = train_data) %>%

Model Fitting

Model 1: Linear Regression

# Linear regression model spec
lm_spec <- linear_reg() %>%
  set_engine("lm")

# Workflow
lm_wf <- workflow() %>%
  add_recipe(oop_recipe) %>%
  add_model(lm_spec)

# Cross validation
lm_cv <- fit_resamples(
  lm_wf,
  resamples = folds,
  metrics = metric_set(rmse, rsq)
)

# CV metrics
lm_metrics <- collect_metrics(lm_cv)

Model 2: LASSO Regression

# LASSO spec with penalty tuning
lasso_spec <- linear_reg(penalty = tune(), mixture = 1) %>%
  set_engine("glmnet")

# Workflow
lasso_wf <- workflow() %>%
  add_recipe(oop_recipe) %>%
  add_model(lasso_spec)

# Set up tuning grid
lasso_grid <- grid_regular(penalty(range = c(-4, 1)), levels = 30)

# Tune the penalty
lasso_tune <- tune_grid(
  lasso_wf,
  resamples = folds,
  grid = lasso_grid,
  metrics = metric_set(rmse, rsq)
)

# LASSO penalty

The random forest model performed the best, with the lowest RMSE and highest R² out of the three models. I selected it as the final model because it can capture more complex, non-linear relationships between different sources of health spending and out-of-pocket burden. This makes sense given how varied health financing systems are across countries with different income levels and structures. While linear regression is easier to interpret, the better predictive performance of the random forest makes it a stronger choice for this analysis.

Discussion

This analysis used WHO global health spending data to examine whether a country’s out-of-pocket (OOP) payment burden can be predicted based on its mix of government, private, and external health spending.

The random forest model performed the best, with a cross-validated RMSE of 6.45 and an R² of 0.895. It performed even better on the test set, with an RMSE of 6.06 and an R² of 0.913, meaning the model explained about 91% of the variation in OOP burden on data it had never seen before.

Government spending share was the strongest predictor of OOP burden. Countries that rely more on government funding tend to have lower out-of-pocket costs for individuals, since public financing reduces direct payments at the point of care. This aligns with long-standing research showing that expanding public health coverage is one of the most effective ways to reduce financial hardship (World Health Organization, 2024).

The EDA showed a general decline in OOP burden globally from 2000 to 2023, reflecting progress toward universal health coverage. However, many countries in South and Southeast Asia and sub-Saharan Africa still have OOP burdens above 60% of total health spending, which remains a major concern.

One limitation is that this analysis treats each country-year as independent, even though repeated observations from the same country are likely correlated. A more rigorous approach would account for this clustering using mixed effects models.
